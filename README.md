# Adulting Not Allowed

An edgy, neon street-art landing page for taking a break from being responsible.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy on Vercel

1. Import this GitHub repository into Vercel.
2. Leave the framework preset as **Other**.
3. Leave the build command blank.
4. Deploy.

The site is plain static HTML, CSS, and JavaScript, so no build step or environment variables are required.
